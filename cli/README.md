# Bluto Box CLI

Upload a file from the command line and get back a share link, no browser needed.

```
node cli/upload.mjs path/to/file.zip
```

Uses the same public API as anonymous uploads on the site, so the same limits apply: 200MB max file size, 10 uploads/hour per IP. No account or API key required.

Not yet published to npm, run it directly from a local clone of this repo.
